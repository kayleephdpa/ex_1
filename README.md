# 매출 인사이트

`index.html`을 더블 클릭하면 실행됩니다. 별도 설치나 빌드가 필요하지 않습니다.

## 데이터 교체

- 상단의 `엑셀 불러오기`를 누르거나 현재 데이터 카드에 파일을 끌어다 놓습니다.
- `.xlsx`, `.csv` 파일을 지원합니다.
- 첫 번째 열은 날짜, 나머지 열은 기업별 숫자 매출액인 형식을 권장합니다.

## 개인정보 및 보안

파일 읽기, 집계, 차트 생성은 모두 현재 브라우저에서 실행됩니다. 외부 API, CDN, 분석 서비스를 사용하지 않으며 업로드한 데이터를 네트워크로 전송하지 않습니다.
